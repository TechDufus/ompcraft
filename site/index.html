Your AI coding agents, in your quest log

Watch your omp agents work without leaving World of Warcraft: Forever. A native objective tracker, achievement pop-ups when one finishes or needs you, and every reply on parchment, one click away.

[ompcraft] Install in one line, then start the game:

Every agent, at a glance

Agents sit in a quest-style tracker, top left by default, or under your objectives or wherever you drag it, grouped by Tern session. Working agents show what they're doing right now and how far through their todo list they are. Idle ones fold into a single line, so the list stays short.

Quest markers

  • Needs you. It asked a question and is waiting.
  • Finished. You haven't looked yet.
  • Working. Live activity and todo progress.
  • Failed or exited. Something went wrong.

Remote hosts attached to your Tern window show up too, labelled with their name.

Read the reply without alt-tabbing

Click an agent and its last reply opens on parchment, formatted the way it was written: headings, nested lists, inline code, code blocks and tables. Below it are the turn's recent tool steps, and the model and session it ran in.

Agent page

Up to 12 lines of each code block, indentation intact

Recent steps marked done, failed or running

Resize it; it remembers

Reply text never leaves your PC. Keep it out of the game entirely with ompcraft config detail off

Pop-ups that wait until you're out of combat

When an agent finishes, needs you, fails or exits, you get an achievement-style pop-up with its time, tokens and cost. Pull a boss and they queue up; they arrive when combat ends.

How it works

WoW addons can't open a socket or read a file. ompcraft passes messages the only ways an addon can notice them: addon files it can load on demand, and sound files whose presence it can check.

Objectives

  1. Your omp agents report to Tern, on this PC or on a remote host1/1
  2. The Tern plugin hands their state to the companion on 127.0.0.1, every 500 ms1/1
  3. The companion writes plain-data Lua into a pre-installed slot addon and rings a doorbell file1/1
  4. The addon hears the doorbell and loads the slot: 67–174 ms in testing, no /reload1/1

Rewards

You will receive:

  • Nothing leaves your PC
  • No screen capture
  • No input sent to the game
  • Snapshot files wiped when the game or companion exits

Is it safe?

Unofficial fan project · Not approved by Blizzard

Uses: public addon APIs, plus a separate program that writes data files into your Interface/AddOns folder. WeakAuras Companion and the TSM and Wago apps have done the same for years.

Never: reads or changes game memory · injects into the client · captures your screen · sends keystrokes, clicks or controller input · plays the game for you.

Respects combat lockdown, Blizzard's secret-value restrictions and the add-on policy: free, visible source, no ads, no chat spam.

"No Blizzard text approves or forbids a tool like this. It relies on undocumented client behaviour that can change at any time. Use it at your own risk."
